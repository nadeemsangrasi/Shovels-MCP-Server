# Codex Setup

Configure Shovels with OpenAI Codex CLI.

## Prerequisites

- Codex CLI installed
- A Shovels API key

## Configuration

Add Shovels to your Codex config (`~/.config/codex/config.toml`):

```toml
[mcp_servers.shovels]
url = "http://localhost:8000"
http_headers = { "X-API-Key" = "YOUR_API_KEY" }
```

## Usage

Once configured, Codex can access Shovels tools:

```
shovels_permits(geo_id="TX", permit_from="2026-01-01", permit_to="2026-06-30")
```

## Troubleshooting

- Ensure the Shovels server is running
- Verify the URL and port in your configuration
- Check that your API key is correct
