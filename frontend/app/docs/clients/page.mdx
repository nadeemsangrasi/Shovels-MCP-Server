# All MCP Clients

Shovels works with any MCP-compatible AI agent. Below are configuration examples for popular clients.

## Configuration

All clients use the same MCP server configuration pattern:

```json
{
  "mcpServers": {
    "shovels": {
      "url": "https://shovels-mcp-server.onrender.com/mcp",
      "headers": {
        "X-API-Key": "your-shovels-api-key"
      }
    }
  }
}
```

For local development, Shovels runs on `https://shovels-mcp-server.onrender.com/mcp` by default.

## Getting Your API Key

To use Shovels, you need a Shovels API key:

1. Sign up at [app.shovels.ai](https://app.shovels.ai)
2. Generate a new API key
3. Replace `YOUR_API_KEY` in the configurations above with your actual key
