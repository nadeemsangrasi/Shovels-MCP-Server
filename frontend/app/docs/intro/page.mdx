# Shovels MCP Server

Shovels MCP brings U.S. building permit data to your AI coding assistant through the Model Context Protocol (MCP). Instead of scraping municipal websites or parsing PDFs, your agent queries structured data directly.

## ❌ Without Shovels

Accessing building permit data is fragmented and manual:

- ❌ Scraping individual city and county websites
- ❌ Parsing inconsistent PDF formats
- ❌ No unified schema across jurisdictions
- ❌ Manually tracking permit status across multiple portals

## ✅ With Shovels

Shovels provides a unified MCP interface to U.S. building permits, contractor records, and zoning decisions — all from within your AI coding assistant.

```txt
Find recent commercial building permits in Austin, Texas with job values over $100,000.
```

```txt
Search for electrical contractors in Seattle who have completed residential work this year.
```

Shovels MCP connects your agent to structured construction data across the United States.

- 1️⃣ Resolve locations with intuitive geo queries
- 2️⃣ Search permits, contractors, and decisions with rich filters
- 3️⃣ Get structured JSON data your agent can use immediately

No municipal website scraping, no PDF parsing, no manual lookups.
